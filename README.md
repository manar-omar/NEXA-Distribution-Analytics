# NEXA Distribution Analytics

## Overview

NEXA Distribution Analytics is an end-to-end Business Intelligence project designed to analyze logistics operations, transportation efficiency, reconciliation controls, and collections performance.

The project covers the complete analytics lifecycle:

- Data Profiling
- Data Quality Assessment
- Data Cleaning
- Data Modeling
- SQL Analysis
- Power BI Dashboard Development
- Business Insights & Recommendations

---

## Business Problem

Management observed increasing transportation costs, operational exceptions, reconciliation gaps, and collection-performance challenges.

This project investigates:

- Transportation cost growth
- Logistics efficiency
- Vehicle utilization
- Reconciliation exceptions
- Collections performance
- Outstanding receivables

## Key Findings

### Transportation Performance

- Transportation cost increased by approximately **60%**.
- Shipment volume increased by approximately **19%**.
- Cost per KG increased by approximately **34%**.

### Regional Analysis

The highest transportation cost per KG was observed in:

- Luxor
- Sohag
- Assiut

### Transporter Performance

**Best Performing Transporter**
- Delta Freight

**Lowest Utilization Transporter**
- Horizon Cargo

### Vehicle Utilization

**Highest Utilization Vehicle Type**
- Medium Truck 3.5T

**Lowest Utilization Vehicle Type**
- Pickup 1T

### Collections Performance

- Outstanding Receivables reached **12.01M EGP**
- Average Collection Cycle = **40.91 Days**
- Average Payment Delay = **11.02 Days**

## Recommendations

### Improve Transportation Efficiency

- Optimize route planning.
- Monitor Cost per KG.
- Reduce low-load trips.

### Strengthen Exception Management

- Accelerate invoice follow-up.
- Improve reconciliation controls.
- Monitor delivery shortfalls.

### Improve Collections Performance

- Prioritize overdue receivables.
- Monitor payment delays.
- Improve collection cycle performance.

### Optimize Fleet Allocation

- Increase utilization of high-performing vehicle types.
- Review underutilized vehicle categories.
